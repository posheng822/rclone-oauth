隱私權政策 / Privacy Policy

本政策適用於個人使用的 rclone Google Drive OAuth 應用程式。此應用程式使用者在自己的電腦上執行 rclone，不提供獨立的雲端後端服務。 This policy applies to a personally operated Google Drive OAuth client used with rclone on the user's own computer; no separate cloud backend is provided.

1. 存取的資料 / Data accessed

Google Drive OAuth 權限為 https://www.googleapis.com/auth/drive.file。rclone 可透過 Google Drive API 存取、上傳、下載、修改及刪除由此應用程式建立或獲使用者授權的檔案與資料夾；不要求完整雲端硬碟的 drive 權限。 The requested scope is drive.file. Via Google Drive API, rclone may list, upload, download, edit, and delete files or folders created by the application or specifically authorized by the user. It does not request full-Drive drive access.

2. 使用目的 / Use of data

資料僅用於使用者主動執行的雲端備份、檔案管理與同步作業。此靜態網站不會透過 OAuth 取得或處理 Google Drive 檔案。 Data is used solely for user-directed backup, file management, and synchronization. This static website does not obtain Google Drive files via OAuth.

3. 儲存與安全 / Storage and security

OAuth 憑證與更新權杖由本機 rclone 設定檔管理，可能包含可存取 Google Drive 的機密資訊。使用者應保護作業系統帳號及設定檔，不應將憑證提交至公開儲存庫。Google Drive 內容仍由 Google 儲存。 OAuth credentials and refresh tokens are managed in the local rclone configuration and must be protected. They should never be committed to a public repository. Google Drive content remains stored by Google.

4. 分享與第三方 / Disclosure and third parties

本 OAuth 整合不會販售使用者資料，也不會自行將 Drive 檔案傳送至額外的營運伺服器。執行雲端檔案操作需要與 Google Drive API 通訊。此說明網站由 GitHub Pages 託管；GitHub 可能依其政策處理網頁存取紀錄。 This integration does not sell user data or independently transmit Drive content to an additional operator-run server. Drive operations communicate with Google's API. This page is hosted on GitHub Pages, which may process website access logs under its own policies.

5. 保留與撤銷 / Retention and revocation

檔案保留期間由使用者在 Google Drive 的操作決定。使用者可隨時在 Google 帳號的第三方連線管理頁 撤銷應用程式授權；撤銷後，本機既存的設定檔仍需自行妥善保護或移除。 File retention is controlled by the user's own Drive operations. Access can be revoked at Google Account third-party connections. Local configuration copies remain the user's responsibility.

6. 政策更新 / Changes

若存取範圍或使用方式改變，將更新本頁政策。 This policy will be updated if access scopes or data practices change.

Personal rclone Google Drive Connection

這是供個人電腦上的 rclone 命令列程式連接 Google Drive 使用的獨立 OAuth 設定說明頁。此專案沒有對外開放的網頁檔案管理服務。

This page describes a personal OAuth client used by the rclone command-line program to access Google Drive from a local computer. It does not operate a public file-management service.

用途與功能 / Purpose

  • 使用者透過 Google OAuth 授權，讓本機 rclone 在 Google Drive 中建立及管理備份檔案與資料夾。 / The user authorizes local rclone to create and manage backup files and folders in Google Drive.
  • 應用程式要求 https://www.googleapis.com/auth/drive.file 權限，主要用於存取由此 OAuth 應用程式建立或經使用者明確授權的檔案。 / The application requests the drive.file scope for files it creates or that the user explicitly authorizes.
  • Google Drive 的資料存取與操作由使用者在自己的電腦上執行；此靜態網站不讀取 Google Drive 檔案。 / Google Drive operations are performed locally; this static website does not read Drive files.
本網站只提供 OAuth 應用程式的公開說明與政策資訊，不需要你在此輸入 Google 密碼、Client Secret 或 OAuth Token。 This website does not request Google passwords, client secrets, or OAuth tokens.
